Testing is staged: each subsystem is tested on its own first, and the cart is tested as a whole once all of them work. Table~\ref{tab:test-plan} links each stage to the specification IDs in Table~\ref{tab:proposal-specs}, and a stage that exercises several specifications at once lists all of their IDs. These tests verify the requirements, and they need only a controlled grass area, a tape measure, a laser rangefinder for reference distances, and video for timing. Validation is a final trial in which a golfer plays a hole using only the cart, with no phone. A safety operator holding the emergency stop is present for every test in which the cart moves.
