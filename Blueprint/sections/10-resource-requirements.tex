
\CourseSection{Resource Requirements}
\label{sec:resources}

The Autonomous Smart Caddy Cart (ASCC) will be developed using a combination of existing laboratory equipment, previously acquired components, and purchased hardware. Resource selection is guided by the system requirements, subsystem dependencies, and the project budget of CAD \$600. The team will prioritize components needed for motor control, golfer following, obstacle detection, emergency stopping, and RFID-based club identification before acquiring hardware for additional features.

\CourseSubsection{Hardware and Equipment}

The Raspberry Pi 5 will serve as the primary computing platform for sensor processing and high-level control. A motor controller will interface with the drive system of a used motorized golf push cart, which provides the mechanical platform for the prototype. Ultrasonic sensors and a TF-Luna LiDAR sensor will support obstacle detection and distance measurement, while RFID readers and tags will support club identification.

\CourseSubsection{Development Facilities and Software}

The project will require access to electronics workspaces, soldering equipment, multimeters, power supplies, and mechanical assembly tools for subsystem prototyping and integration. Software development will use Python and the Raspberry Pi development environment, with version control used to coordinate changes across team members.

Initial testing will take place in a controlled indoor environment where obstacle placement, operating speed, and emergency-stop behaviour can be evaluated safely. Outdoor testing will require a suitable area with permission for operation, sufficient space for the cart, and representative terrain conditions. Access to facilities and test equipment will be confirmed before the corresponding validation milestones.

\CourseSubsection{Budget and Procurement Contingencies}

The estimated total project cost is CAD \$595, leaving CAD \$5 below the project budget limit of CAD \$600. The estimate includes a \$15 contingency allowance, but the small remaining margin makes the project sensitive to changes in cart pricing, shipping costs, and component availability.

If the selected cart exceeds the budget or is unavailable, the team will evaluate alternative second-hand platforms before committing to additional purchases. Existing components and laboratory equipment will be reused wherever practical. Optional features will be deferred if necessary to preserve resources for the core following, obstacle detection, emergency-stop, and club-tracking functions.
