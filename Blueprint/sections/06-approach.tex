\section{Development Approach and Milestones}

\subsection{Prototype purpose and exit gates}
P01 validates safe wheel actuation without autonomous control; P02 establishes reliable tagged-club detection; P03 establishes target ranging and a bounded speed request; P04 verifies independent safety overrides; P05 checks GPS-to-green calculations and display; P06 validates interface compatibility without moving; P07 verifies the complete operating scenario. A prototype advances only after its linked acceptance test passes or a documented corrective action is accepted.
\subsection{Contingencies and dependencies}
P01 is prerequisite for moving P03/P04 trials. P04 safety acceptance precedes P07. If RFID reliability fails, reposition antennas or use slot-level sensing; this affects M05 but not safe mobility. If target ranging fails, restrict motion to controlled manual/remote operation while redesigning P03; do not claim autonomous-following completion. If GPS accuracy fails, report unavailable/unreliable distances rather than false precision. Preserve M09--M10 integration buffer by deferring stretch features.\par
