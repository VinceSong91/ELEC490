# ASCC Blueprint -- ELEC 490/498

This is a **working draft**, derived from the October 2026 proposal and bp_rubric.pdf. It is not submission-ready: confirm the schedule, requirements, suppliers, citations, safety SOP, logo and test setup.

## Build
Run `./build.sh` (TeX Live with latexmk and biber), or upload this folder to Overleaf and set `main.tex` as root.

## Structure
- `main.tex`, `preamble.tex`, `references.bib` -- root LaTeX project
- `sections/` -- separate rubric-aligned sections
- `figures/` -- place original vector figures and team logo here
- `bp_rubric.pdf` -- original marking criteria
- `original_proposal.pdf` -- project source document

## Important

All acceptance thresholds are proposal-derived or marked for confirmation. Budget sources and standards need to be added; no measured outcomes are claimed. Check body length before submission.
